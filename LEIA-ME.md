# Atualizar a Central de Chamados no GitHub Pages

Extraia o ZIP. Na raiz da branch main do repositório joaoelcio/central-chamados, envie index.html, colina.png, abrir.html, consultar.html e .nojekyll. Confirme a substituição das versões antigas e faça o commit.

Quando o GitHub concluir a publicação, abra https://joaoelcio.github.io/central-chamados/ e teste os botões Entrar como usuário e Painel de TI. O GitHub publica a página inicial. A autenticação, os chamados e o painel ficam no servidor da Central.
